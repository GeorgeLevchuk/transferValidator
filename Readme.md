# TransferValidator

TransferValidator это сервис, который проводит валидацию транзакции.

## Что проверяется

Метод `validate(TransferRequest request)` выбрасывает
`InvalidTransferException` с соответствующим значением `TransferError`,
если обнаружена ошибка:

-   запрос или обязательные поля не заданы;
-   сумма нулевая или отрицательная;
-   количество знаков после запятой превышает допустимое для валюты;
-   счёт отправителя и получателя совпадает;
-   один из счетов не найден;
-   валюта запроса не совпадает с валютой счёта отправителя или
    получателя;
-   сумма превышает лимит отправителя;
-   на счёте отправителя недостаточно средств.

# Все тесты
Тесты можно запустить командой mvn test или mvn -Dtest=TransferValidatorTest test.


## Почему `BigDecimal`

Для денежных сумм используется `BigDecimal`, а не `double` или `long`:
он позволяет точно представлять десятичные значения и сравнивать суммы
без ошибок двоичного округления, при этом `long` сам по себе не хранит
дробную часть.
